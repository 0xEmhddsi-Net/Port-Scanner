# Port-Scanner
**Simple Python Port Scanner**

A lightweight TCP port scanner written in Python.
This tool scans a target host over a specified port range and reports which ports are open.

It’s designed as a beginner-friendly cybersecurity project to demonstrate knowledge of:

Python networking (sockets)

TCP connections

Basic port enumeration

Clean code structure

Command-line interaction

**Features**

Scan any IPv4 target (IP or hostname)

Custom port range input

Detects open TCP ports

Timeout handling for faster performance

Clean and minimal codebase
